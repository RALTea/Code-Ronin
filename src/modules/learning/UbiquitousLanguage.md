**Apprentice**: A person who is learning a programming **language** on the app.

**Language**: A programming language that the **apprentice** is learning, such as Python, JavaScript, TypeScript or Ruby.

**Attempt**: When an **apprentice** tries to solve a coding challenge in a specific **language**. The user submits their solution, and the system evaluates it.

**Task**: A coding challenge or exercise that the **apprentice** must complete using a specific **language**. Each **task** has a unique identifier and a set of requirements.

**Quest**: A collection of related **tasks** that form a larger learning objective. Completing a **task** should contribute to the completion of a **quest**, and unlock the next **task** in the quest's sequence.

**Campaign**: A series of **quests** designed to teach a specific programming concept or skill. Each **campaign** has a unique identifier and a set of **quests**.

**EvaluationCriteria**: The rules and conditions used to assess the correctness and quality of an **apprentice**'s **attempt** at a **task**. This may include checking for correct output, code efficiency, and adherence to best practices.
